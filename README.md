# Antz Software Onboarding Kit

The Antz Onboarding Guide: a web-based, responsive guide to the Antz platform for the staff who use it, built from the original slide-style training kit.

Live site: https://antz-software-onboarding-kit.vercel.app/ (deployed by Vercel from `main`; `vercel.json` serves `antz-onboard/` at the root).

## What's here

| Folder | Contents |
|---|---|
| `antz-onboard/` | The website. Open `index.html` in a browser, or run `python3 serve.py` and visit http://localhost:8080/ |
| `audit/` | Reviews of the site, each as a PDF with its HTML source:<br>`Antz-Onboarding-Usability-Audit.pdf` (24 Sep 2026)<br>`heuristic/` heuristic evaluation (25 Sep 2026)<br>`heuristic-v2/` heuristic evaluation of the current guide (29 Sep 2026)<br>`screenshots/` app screenshot coverage audit and capture checklist (29 Sep 2026) |

See `antz-onboard/README.md` for how the site is put together and how to edit its content.
